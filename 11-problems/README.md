# Python Problems

Practice is one of the best ways to improve your programming skills. This section contains programming problems that help you apply the concepts learned throughout this repository.

**Important:** Try to solve each problem on your own before looking at any solution. The goal is to build problem-solving skills, not just write code.

## Difficulty Levels

### Easy
Focus on the fundamentals of Python:

- Variables
- Input and Output
- Operators
- Conditional Statements
- Loops
- Functions
- Lists
- Strings

### Medium
Combine multiple concepts to solve practical programming problems:

- Lists and Dictionaries
- Functions
- File Handling
- Error Handling
- Object-Oriented Programming

### Hard
Build larger console applications that require planning, program design, and multiple Python concepts working together.
