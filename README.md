# Python Practice

A collection of Python practice programs focused on learning and strengthening Python fundamentals. This repository contains examples and exercises covering core programming concepts, making it useful for beginners and anyone revising the basics.

## Features

* Beginner-friendly Python programs
* Well-organized practice files
* Covers essential Python concepts
* Easy to understand and modify

## Topics Covered

* Variables and Data Types
* Input and Output
* Operators
* Conditional Statements (`if`, `elif`, `else`)
* Loops (`for`, `while`)
* Functions
* Strings
* Lists
* Tuples
* Dictionaries
* Sets
* Exception Handling
* File Handling
* Modules and Packages
* Object-Oriented Programming (Basics)

## Getting Started

### Prerequisites

* Python 3.10 or later

### Clone the Repository

```bash
git clone https://github.com/<rafiverse004>/Python-practice.git
cd Python-practice
```

### Run a Program

```bash
python filename.py
```

or

```bash
python3 filename.py
```
